# Toxicity Moderation System

Система автоматической модерации токсичных комментариев.

## Библиотеки

- PyTorch — нейросети
- HuggingFace Transformers — модель RuBERT

## Модель

RuBERT — русскоязычная версия BERT.

## Датасеты

- Russian Hate Speech (14k) — бинарная классификация
- Toxic Russian Comments (100k+) — 4 класса
- Russian Inappropriate Messages (150k) — бинарная + темы
