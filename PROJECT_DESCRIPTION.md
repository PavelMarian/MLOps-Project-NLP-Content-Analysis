## 2. Цели и задачи проекта

### Бизнес-цель

Разработать автоматизированную систему премодерации/постмодерации контента, которая снизит нагрузку на людей-модераторов на 70% и повысит лояльность пользователей за счёт создания здоровой дискуссии в комментариях.

### Ключевые задачи

| Задача | Описание |
|--------|----------|
| Бинарная классификация | Отличить токсичный комментарий от нейтрального |
| Многоклассовая классификация | Определить тип токсичности (оскорбление, угроза, нецензурная лексика) |
| Детекция неуместности | Выявить сообщения, наносящие репутационный ущерб |
| Гибридная модерация | 70% простых случаев автоматически, 30% сложных — на проверку человеку |
| API для интеграции | Предоставить HTTP-эндпоинты для вызова модели |

### Целевые KPI

- Снижение времени реакции на жалобу: с 2 часов до 5 минут
- Сокращение штата модераторов: на 30% без потери качества
- Автоматическая обработка: 70% всех комментариев
- False Positive (ложная блокировка): менее 1%
- False Negative (пропуск токсичности): менее 10%

## 6. Модели машинного обучения

### 6.1. Выбранная архитектура

**RuBERT** — русскоязычная версия BERT от DeepPavlov и SberDevices.

| Параметр | Значение |
|----------|----------|
| Базовая модель | BERT-base |
| Язык | Русский |
| Размер | ~180 млн параметров |
| Входной размер | до 512 токенов |

**Почему RuBERT:**
- Лучшая среди open-source моделей для русского языка
- Есть готовые веса (fine-tuning потребует меньше данных)
- Поддерживается HuggingFace Transformers

### 6.2. Планируемые модели

| Модель | Задача | Обучающий датасет |
|--------|--------|-------------------|
| RuBERT-binary | Бинарная классификация (токсичный/нетоксичный) | Russian Hate Speech (14k) |
| RuBERT-multiclass | Многоклассовая классификация (4 типа) | Toxic Russian Comments (100k+) |
| RuBERT-inappropriate | Детекция неуместности (бинарная + темы) | Inappropriate Messages (150k) |

### 6.3. Пороги принятия решений

| Вероятность токсичности | Действие |
|-------------------------|----------|
| > 75% | Карантин (не виден другим) |
| 50% - 75% | Приоритетная проверка модератором |
| < 50% | Публикация |

## 9. Риски и их митигация

| Риск | Вероятность | Последствия | Митигация |
|------|-------------|-------------|-----------|
| **False Positive** (хороший комментарий заблокирован) | Средняя | Уход пользователей | Карантин вместо удаления, апелляция |
| **False Negative** (плохой комментарий пропущен) | Средняя | Жертва токсичности покинет платформу | Система жалоб, очередь модератору |
| **Предвзятость модели (Bias)** | Высокая | Обвинения в цензуре и дискриминации | Балансировка датасетов, аудит модели |
| **Высокая стоимость GPU** | Высокая | Превышение бюджета | CPU для простых случаев, кэширование |
| **Обход фильтров** (замена букв, пробелы) | Высокая | Снижение эффективности | Нормализация текста, словари-ловушки |
| **Сложный контекст** (сарказм, ирония) | Высокая | Неверная классификация | Человек на сложных случаях (30%) |
